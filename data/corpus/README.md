The CBSA effective date is the page's `dcterms.modified` date; the memorandum's own issue date ("Ottawa, ...") is noted when it differs. No newer CARM-era invoice memorandum was found: D1-4-1 is still the invoice reference, with a CARM transition notice on the page.

Invoice findings cite only D1-4-1 (CI1 fields), 19 CFR 141.86, RGCE reglas 3.1.8 and 1.9.19, Annex B of Delegated Regulation 2015/2446 or the CDS completion guide, and X11 only 19 CFR 149.3; the EORI, ICS2 and TCA rules cite their own documents (`citationScope` in `packages/agent/src/cite.ts`). The marking, origin and valuation documents are searchable (`cli.js search`) but would otherwise outrank the field definitions for terms like "country of origin" or "price paid or payable".

- `npm run corpus:fetch` downloads and converts the sources again (`scripts/fetch-corpus.mjs`; Mexico, EU and UK sources in `scripts/corpus-intl.mjs`). `-- --authority anam,ucc,hmrc` fetches only some authorities.

Sources and licences of the Mexico, EU and UK documents:

- **Mexico**: official text from the Diario Oficial de la Federación (`dof.gob.mx`, without `www`: that host's certificate does not match). Only the rules DocCheck cites are kept. The Ley Aduanera (artículos 36, 36-A, 54 and 59) is read from the Cámara de Diputados PDF when that host answers; it did not from the machine that built this corpus, so it is not included yet and the fetch skips it with a warning.
- **EU**: EUR-Lex answers scripts with a bot challenge, so the XHTML comes from the Publications Office (Cellar, `publications.europa.eu/resource/celex/<CELEX>` with `Accept: application/xhtml+xml`), which serves the same documents; the files link to EUR-Lex. EU legal texts may be reused with acknowledgement of the source (Commission Decision 2011/833/EU); only the Official Journal text is authentic.
- **UK**: GOV.UK content API (`www.gov.uk/api/content/<path>`), under the Open Government Licence v3.0. Data element pages keep only the elements DocCheck checks, each repeated as the first sentence of its section so the quoted passage names it.
- `npm run corpus:index` embeds the chunks with the local model (`EMBED_MODEL`, default `bge-m3`) into `index/<model>.json`.

Citations are informational and may lag behind the official text; always confirm against the source URL.
